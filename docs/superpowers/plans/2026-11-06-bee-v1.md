# Bee v1 Implementation Plan

> **For agentic workers:** execute task by task under `worktree-dispatch`, one fresh worker per task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One live board, held by every attached browser, Claude session and an always-on host, that agents redraw as A2UI surfaces. The brainstorming visual companion runs on it.

**Architecture:** Every peer holds a kuilt replica of one `BoardState` lattice. Browsers hold theirs in wasm, behind the stock A2UI Lit renderer. Claude sessions hold theirs in a JVM MCP bridge. Everyone reaches the JVM host over outbound WebSockets: the host relays the board, keeps it on disk, and is the single Raft voter that commits claims.

**Tech Stack:** Kotlin Multiplatform (JVM + wasmJs), Gradle 9.4.1, JDK 25, kuilt (`kuilt-crdt`, `kuilt-quilter`, `kuilt-websocket`, `kuilt-gossip`, `kuilt-cluster`, `kuilt-raft`, `kuilt-liveness`, `kuilt-store`), Ktor 3.5.2 (Netty server; JS client engine in the browser), A2UI v0.9 via `@a2ui/lit@0.9.1` + `@a2ui/web_core@0.9.1`, MCP Kotlin SDK `io.modelcontextprotocol:kotlin-sdk-server:0.16.0`, Playwright for browser end-to-end tests.

**Spec:** `docs/superpowers/specs/2026-11-06-bee-design.md` (merged in tractat-us/bee#1). Executors read both. Section references below (§n) point into it.

## Global Constraints

- Every shell command below runs after `source ~/.sdkman/bin/sdkman-init.sh && sdk use java 25.0.2-tem`.
- A2UI **v0.9.1** with the official **Lit** renderer, imported from the packages' `v0_9` entry points (`@a2ui/lit/v0_9`, `@a2ui/web_core/v0_9`); message `version` is `"v0.9"`. Pin both npm packages at exactly `0.9.1`. Re-pin when v1.0 lands; any other re-pin is Iain's call, so report it and don't make it yourself.
- The renderer is stock and never sees a CRDT. Merge rules live only in the replica.
- Consume kuilt by coordinates (Tigris `s3://maven/`, the `TigrisKuilt` block from `fireworks-compose/settings.gradle.kts`, `S3_BUILD_CACHE_*` credentials). Version: `0.7.0-dev.1641` or newer, the same for every module, via `kuilt-bom`. Composite: `if (file("../kuilt").exists()) includeBuild("../kuilt")`.
- **Never fork, vendor or monkey-patch kuilt.** A gap is a `tractat-us/kuilt` issue (search first). A Bee workaround sits behind a comment naming that issue. Report every issue you file.
- Everyone talks through the host over WebSockets, outbound only. No WebRTC, no inbound connection to any peer except the host.
- `Sketch` content runs only in an `<iframe sandbox="allow-scripts">` (never `allow-same-origin`), with no network beyond the page. Neither host nor client executes surface content outside that sandbox.
- Nothing reassigns itself. An orphaned claim stays held and flagged until a participant decides.
- Records are addressed to a surface, never to a session instance. Handling a record always goes through a claim.
- In v1 the voter set is the host alone. The host votes and never claims.
- "Clear the board" closes surfaces and never deletes them.
- Bridge tools make "this goes on the shared board" an explicit act, never a side effect of another tool.
- Tests: no `test` prefix on test names; multi-assert tests use `us.tractat.kuilt.test.assertAll` (from `kuilt-test`).
- Changes go through PRs, one PR per task. Never use the word "chore" in commits or PR titles. `next-plan.md` and `morning-report*.md` are never committed.

## Review Focus

1. **Malformed agent-supplied A2UI** (no `root` component, a child id that names no component, a component type outside the Notions catalog). Expect the bridge tool to refuse with an error that names the bad id or type, and leave the board unchanged. Nobody's screen shows a broken surface. Test: Task 3, `BeeToolsTest.openRefusesMalformedComponents`.
2. **Markup in non-`Sketch` text** (a title, a `Text`, a poll option or card label containing `<img onerror=…>`). Expect it shown as literal text. Only `Sketch` ever interprets HTML. Test: Task 8, `notions.spec.mjs` › `markup in labels renders as text`.
3. **A wait that ends badly**: `bee_wait_action` times out, or the call is cancelled (the client's tool timeout, `/clear`) after the bridge claimed a record but before it returned it. Expect no claim left held by a wait nobody is in. Test: Task 3, `BridgeWaitTest.cancelledWaitReleasesItsClaim`.
4. **The host is down when someone acts.** Expect the edit to land locally, the page to say it's offline, and the edit to sync on return. A claim returns `Unavailable` and never `Won`. If the timed-out proposal commits later, the bridge releases it. Test: Task 4, `ClaimsClientTest.lateCommitOfTimedOutClaimIsReleased`.
5. **An oversized payload**: a `Sketch` mockup with inline images above the seam's `maxPayloadBytes`. Expect a refusal that states the limit, and a board that keeps working. Test: Task 5, `SketchSurfaceTest.oversizedSketchIsRefusedWithItsLimit`.

## Decisions this plan makes (spec §10)

- **MCP tools:** `bee_board`, `bee_surface_open`, `bee_surface_update`, `bee_surface_close`, `bee_board_clear`, `bee_wait_action`, `bee_action_done`, `bee_claim`, `bee_release`, `bee_presence`. Each description opens with "Puts … on the shared board, visible to everyone attached" when it writes.
- **Which records a session handles:** subscription by surface. A session handles a surface by calling `bee_wait_action(surfaceId)` on it, and nothing else declares it. Any session may wait on any surface, so a surface whose opener died can still be served.
- **Quiet timeout:** 20 minutes since the bridge's last tool call. A session blocked inside `bee_wait_action` is not quiet. **Crash grace:** a lost link is declared a crash after the heartbeat reconnect window of 30 seconds.
- **Layout:** open surfaces stack vertically in `openedAt` order, ties broken by surface id. Closed surfaces sit in a collapsed history strip, newest first, and reopen with their records.
- **The A2UI mapping** lives in `bee-a2ui`, which depends only on `kuilt-crdt`, so it can graduate. Whether it does is decided after Task 2.
- **Peer identity:** `agent:<name>#<8 hex>` (fresh per bridge identity) and `human:<name>` (one per person across tabs and devices; no instance part). The agent name is `$BEE_SESSION_NAME`, else the basename of the bridge's working directory. The human name is asked once and kept in `localStorage["bee.human.name"]`.
- **CRDT authors are not peer identities:** `web-<uuid>` per page load, `mcp-<uuid>` per bridge process, `host-<uuid>` per host boot. Fabric `PeerId`s are fresh per connection (reconnect shape (A)).
- **Departures are agent-only.** A human's claims never orphan on their own. Closing every tab isn't dying.
- **Host:** port `8233` ("BEE" on a keypad), data dir `~/.bee/host/`. Routes: `/` (the web client), `/ws/board`, `/ws/claims`. It binds loopback until Task 7.
- **Notions catalog id:** `https://tractat.us/bee/catalogs/notions/v1.json`. It holds the basic catalog's components plus `Sketch`, `Board` and `Poll`, because a surface names one catalog.

## kuilt#2869 checkpoint (after the plan)

Inputs read: kuilt `demo/workspace/CONTRACTS.md` at `53f89b34`, and `kuilt-workspace/docs/spikes/2026-10-reconnect-shape.md`.

**What Bee picks up**

- **The input-history contract.** A record is an immutable `Rga` element whose identity is its dot. A correction is a new record, not an edit. Its basis is read once, from the actor's own replica, at the moment it acts. Capturing at the right time is the code's obligation, not the type's, so Task 2 pins it with a test that reds when capture happens late.
- **"A scalar input has no identity."** `JsonNode.Leaf` (an `MVRegister`) contributes no dots, and `ORMap` doesn't aggregate nested dots (kuilt#2177). Bee responds in two ways. Anything a handler must be able to say was or wasn't seen goes in a `JsonNode.Array`, whose `Rga` dots *are* aggregated by `JsonCrdt`: poll options, cards. And a record also keeps a value snapshot of the data it was shown, behind a comment naming the kuilt issue Task 2 files.
- **The two-armed delivery rule** (`causalDots()` ∪ `causalFloor()`). `Basis.saw(dot)` spells it out once. Bee is the second consumer #2869 said `Quilted.delivered(dot)` was waiting for, so Task 2 files that issue (none exists yet) and names it in the comment.
- **"Unknown, never applicable."** A handler whose replica hasn't delivered every dot a basis names gets the record flagged `basisComplete = false`, and never treats it as settled.
- **Reconnect shape (A).** A fresh `Quilter` per connection, seeded from the held state. A stable CRDT author per process. An identity-guarded mirror (`if (conn === c) held.value = s`, under the lock). A merge echo on the hub. Each spoke's `GossipSeam` started on the connection's child scope, because of the spike's candidate leak issue.
- **Not picked up in v1:** the re-check of a shown answer (kuilt#2880). Bee keeps the basis that re-check needs, so it can be added later from the design at `53f89b34`.

**What #2869 could pick up from Bee**

- **A target beyond the JVM.** CONTRACTS establishes nothing off the JVM. Bee captures a basis in wasm in the browser (Tasks 1–2).
- **A second consumer for capture.** CONTRACTS rejected a capture API because one consumer was too few. If `Basis.capture` ends up the same shape as `InputCapture.capture`, that's evidence for naming it in kuilt.
- **The "Authority" pile.** Exactly-once claims through `kuilt-cluster`, with a voter that never claims. Orphaned work decided by any participant (Task 4, Task 8).
- **M5's question**, whether A2UI earns its place, answered for a board with no fixed screen. That includes the `MVRegister` projection rule Task 2 settles.
